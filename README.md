# Self-hosted CRONs

GitHub Action-controlled CRON jobs to run on a self-hosted runner on remote servers.

Follow the instructions from settings for establishing self-hosted runner.

The DANDI and EMBER usage workflows (log extraction, inventory sync, package install and summaries) have moved to
[brain-bbqs-runners/dandi-usage-runner](https://github.com/brain-bbqs-runners/dandi-usage-runner) and
[brain-bbqs-runners/ember-usage-runner](https://github.com/brain-bbqs-runners/ember-usage-runner).
